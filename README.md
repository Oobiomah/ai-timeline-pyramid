# AI Insights: The Timeline Pyramid

An interactive journey into the history and evolution of artificial intelligence.

## Overview

**AI Insights: The Timeline Pyramid** is an interactive web application that presents major milestones in the history of artificial intelligence through a five-layer pyramid.

The project organizes AI's development into chronological stages, allowing users to explore important events, understand their significance, and see how the field has evolved.

## Live Application

[View AI Insights: The Timeline Pyramid](https://oobiomah.github.io/ai-timeline-pyramid/)

## Features

- Five interactive layers representing major stages in AI development.
- Chronological milestone navigation.
- Detailed milestone information, including year, event, significance, AI subfield, and impact.
- Thumbnail previews when hovering over or focusing on milestones.
- Responsive layouts for desktop and mobile screens.
- Independent scrolling within the milestone panel.

## The Five Pyramid Layers

1. **Foundations of AI**
2. **Symbolic AI & Early Systems**
3. **Machine Learning & Deep Learning**
4. **Generative AI & LLMs**
5. **Future AI**

## Problem Statement

The history of artificial intelligence spans several decades, from early ideas about mechanical reasoning and symbolic systems to machine learning, deep learning, generative AI, and emerging approaches to advanced intelligence.

However, this history can be difficult to explore as a connected journey. Important milestones are often presented across different resources, making it challenging for learners to understand their chronological development, relationships, and broader significance.

**AI Insights: The Timeline Pyramid** was developed to make this journey easier to explore through an interactive, chronological presentation of major AI milestones. Its five-layer pyramid organizes the evolution of AI into distinct stages, allowing users to navigate milestones and discover what happened, why it matters, and its impact on the field.

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Oobiomah/ai-timeline-pyramid.git
   ```

2. Navigate into the project directory:

   ```bash
   cd ai-timeline-pyramid
   ```

3. Open `index.html` in a web browser.

No additional dependencies or build tools are required.

## How to Use

1. Open the application.
2. Select any of the five pyramid layers.
3. Explore the milestones displayed in the navigation panel.
4. Select a milestone to view its historical details.
5. Hover over or focus on a milestone to preview its image.
6. Use the navigation controls to return to the milestone list or close the detail view.

## Development Process

The project was developed incrementally, combining historical research, interface design, frontend implementation, testing, and deployment.

1. **Research and content organization:** Compiled 20 AI historical milestones, recording their periods, events, AI subfields, significance, and research references.
2. **Application structure:** Used HTML to organize the application interface and its main components.
3. **Visual presentation:** Used CSS to build the five-layer pyramid, milestone panel, legend, colour scheme, and responsive layouts.
4. **Interactivity:** Used JavaScript to implement layer selection, milestone navigation, milestone details, and thumbnail previews.
5. **Testing and refinement:** Tested the five layers, milestone lists, detail views, navigation controls, thumbnail previews, and mobile layout.
6. **Version control and deployment:** Used Git and GitHub to manage the project and GitHub Pages to publish the application.
